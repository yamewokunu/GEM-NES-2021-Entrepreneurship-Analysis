# GEM-NES 2021 | Comparative Analysis of Entrepreneurial Ecosystems
## Project Overview
This project compares entrepreneurial ecosystem conditions across the United States, South Africa, and Sudan. Leveraging data from the 2021 Global Entrepreneurship Monitor National Expert Survey (GEM NES), the study examines nine distinct entrepreneurial framework dimensions to uncover structural differences, regional nuances, and expert perceptions across diverse economic landscapes.
## Dataset & Scope
•	Source: Global Entrepreneurship Monitor (GEM) National Expert Survey (2021)
•	Comparative Countries: United States, South Africa, Sudan
•	Sample Size: 121 expert responses
•	Evaluation Scope: 9 entrepreneurial framework dimensions
## Tools & Technical Stack
•	Programming Language: Python
•	Data Manipulation & Analysis: Pandas, NumPy
•	Methodology: Data cleaning, transformation, descriptive statistics, and comparative analysis
•	Data Visualization: Plotly (interactive visual representations)
## Deliverables & Repository Structure
•	GEM_NES_2021_Entrepreneurship_Analysis_Clean.ipynb — Comprehensive Python analysis notebook detailing data processing and statistical workflows.
•	GEM_NES_2021_Portfolio_Dashboard_FINAL.html — Standalone interactive dashboard designed for dynamic exploratory data analysis.
## Key Insights & Findings
•	Framework Divergence: The analysis highlights pronounced variations in expert perceptions regarding framework conditions—such as financing, governmental policies, and educational support—between developed and developing entrepreneurial ecosystems.
•	Interactive Exploration: The accompanying Plotly dashboard enables stakeholders to dynamically compare expert ratings across all nine framework dimensions by country.
## Methodological Limitations
Findings are derived from expert perceptions captured during the 2021 survey cycle. Results reflect expert consensus rather than causal performance metrics and should be interpreted as qualitative insights into framework conditions rather than direct measures of startup success.
